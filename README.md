# ID Dental Care Sidoarjo

Company profile website for ID Dental Care Sidoarjo, built with React, Vite, Framer Motion, and Lucide icons.

## Development

```bash
npm install
npm run dev
```

Local preview:

```text
http://localhost:5173/
```

## Build

```bash
npm run build
```

## Notes

The page uses project-local generated visual assets under `src/assets`. Contact details, service copy, and clinic notes are based on the available source materials in this folder.
